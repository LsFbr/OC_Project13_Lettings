Description du projet
=====================

OC Lettings est une application web Django développée pour Orange County Lettings,
une entreprise spécialisée dans la location de biens immobiliers.

L'application permet de consulter les locations disponibles, leurs informations
détaillées, ainsi que les profils utilisateurs associés au site.

Elle comprend notamment :

* une page d'accueil ;
* une liste des locations ;
* une page de détail pour chaque location ;
* une liste des profils utilisateurs ;
* une page de détail pour chaque profil ;
* une interface d'administration Django.

Cette documentation technique présente les informations nécessaires pour installer,
utiliser, maintenir et déployer l'application.
