Guide d'utilisation
===================

Cette page présente les principaux cas d'utilisation de l'application OC Lettings.

Consulter la page d'accueil
---------------------------

La page d'accueil est accessible depuis la racine du site :

.. code-block:: text

   /

Elle donne accès aux principales sections de l'application.

Consulter les locations
-----------------------

La liste des locations est accessible depuis :

.. code-block:: text

   /lettings/

Chaque location dispose d'une page de détail contenant son titre et son adresse.

Consulter les profils
---------------------

La liste des profils utilisateurs est accessible depuis :

.. code-block:: text

   /profiles/

Chaque profil dispose d'une page de détail contenant le nom d'utilisateur et la
ville favorite associée.

Utiliser l'administration Django
--------------------------------

L'interface d'administration est accessible depuis :

.. code-block:: text

   /admin/

Elle permet de consulter et gérer les données de l'application pour les
utilisateurs disposant des droits nécessaires.
