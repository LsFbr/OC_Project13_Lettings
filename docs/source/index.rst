OC Lettings - Documentation technique
=====================================

OC Lettings est une application web Django destinée à la consultation de biens immobiliers et de profils utilisateurs.

Cette documentation technique décrit l'installation du projet, son architecture, ses modèles de données, son utilisation, ainsi que les procédures de déploiement et de gestion de l'application.
